# Парсер Яндекс.Карт: заведения без сайтов

Скрипт `yandex_maps_parser.py` ищет организации в Яндекс.Картах и оставляет
только те, у которых **нет ссылки на сайт** — готовая база «холодных» лидов
для продажи услуг веб-разработки/продвижения.

## Как это работает

Внутренний API Яндекс.Карт закрыт CORS и требует ключа, поэтому парсер через
**Playwright** открывает реальную страницу поиска и перехватывает ответы
эндпоинтов результатов поиска (`search/list` и др.). Сайт заведения определяется
по **всем** полям карточки: `urls.items`, `business_site`/`site`, блок
«Расширенные данные» (`extended_data`), контакты и общий поиск http-ссылок в JSON
карточки. Ссылки на сами Яндекс.Карты, аватарки/статику Яндекса и соцсети
(VK, Telegram, WhatsApp и т.п.) сайтом **не считаются**. Если реальный внешний
сайт не найден — организация попадает в результат.

Из карточки извлекаются: название, адрес, телефоны, рейтинг, число отзывов,
категории, ссылка на карточку в Картах.

## Установка

```bash
pip install playwright
playwright install chromium
```

## Использование

```bash
# Москва, автосервисы, до 300 карточек → CSV
python yandex_maps_parser.py --city "Москва" --query "автосервис" \
    --max-cards 300 --out moscow_autoservice.csv

# Только с рейтингом >= 4 и хотя бы одним отзывом
python yandex_maps_parser.py --city "Казань" --query "стоматология" \
    --min-rating 4 --min-reviews 1

# Показать браузер + сохранить JSON
python yandex_maps_parser.py -q "барбершоп" --headed --json out.json

# Тест без браузера (проверка логики разбора на дампе)
python yandex_maps_parser.py --demo
```

### Ключевые опции

| Флаг | Описание | По умолчанию |
|---|---|---|
| `--city` | город поиска | Москва |
| `--query`, `-q` | категория / запрос | автосервис |
| `--max-cards` | максимум карточек за прогон | 200 |
| `--out`, `-o` | файл CSV (UTF-8 BOM, открывается в Excel) | no_website.csv |
| `--json` | дополнительно сохранить JSON | — |
| `--min-rating` | минимальный рейтинг | 0 (любой) |
| `--min-reviews` | минимальное число отзывов | 0 |
| `--all` | не фильтровать «без сайта», вывести всё | — |
| `--headed` | показать окно браузера (удобно против капчи) | — |
| `--demo` | тест парсера без сети | — |

## Формат CSV

`name, address, phones, rating, reviews, categories, websites, has_website, yandex_maps_url`

## Примечания

- Яндекс может показать капчу — тогда сохранится `captcha.png`; запустите со
  флагом `--headed` и пройдите её вручную.
- Не ставьте слишком большой `--max-cards` за один прогон и делайте паузы
  между запусками — это снижает риск блокировки.
- Собираемые данные — публичные карточки организаций; сверяйтесь с
  пользовательским соглашением Яндекс.Карт.
